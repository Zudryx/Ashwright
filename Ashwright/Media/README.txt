Optional fonts for Ashwright
============================

Ashwright uses the game's own fonts until you add these two files here:

  Title.ttf   used for names, the zone name and tooltip titles
  Body.ttf    used for bar text, hotkeys, chat and nameplates

The mockups used Cinzel (titles) and Alegreya Sans (body). Both are free
under the SIL Open Font License: download them from Google Fonts, rename
the weights you want to Title.ttf and Body.ttf, put them here and /reload.

If you ship the fonts inside the addon, include each font's OFL.txt next to
it, as that license requires.
